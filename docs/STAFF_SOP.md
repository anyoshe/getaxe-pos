## 1. Start of day

1. Log in with **your** user (never share admin password).
2. Confirm **warehouse** on POS matches the stock room you sell from.
3. Count opening cash in the drawer if your manager requires it → **Finance → Daily reconciliation** (optional open count).

## 2. Selling (POS)

| Situation | Action |
|-----------|--------|
| Walk-in cash / M-Pesa / card | **Cash sale** → choose payment method → complete |
| Customer on credit | **Credit invoice** → select **credit customer** (must exist with credit allowed) |
| Medicine with batch/expiry | Select **batch / expiry** (FEFO) before complete |
| Serialized item | Tick required **serials** |
| Loyalty / points | Enter phone when customer asks (optional) |

**Scan mode:** scan or type SKU/name → lines appear → batch on each line → Pay → Complete.  
**Browse mode:** pick from catalogue the same way.

**Do not** use Dispensing instead of POS for normal paid sales unless the manager’s SOP says so.

## 3. Stock in

| Type | Where |
|------|--------|
| Goods from supplier (ordered) | **Purchases → Orders** (approve) → **Receiving / GRN** → batch & expiry if required |
| Old stock already owned | **Opening stock** / receive opening — **not** a fake PO |
| Wrong qty after count | **Inventory** adjust / cycle count (authorized users only) |

## 4. Money out / in (non-POS)

| Type | Where |
|------|--------|
| Pay supplier invoice | **Purchases → Supplier invoices** → pay **from the correct till** (cash/bank/M-Pesa) |
| Shop expense | **Finance → Expenses** |
| Extra income (not POS) | **Finance → Other income** |
| Customer pays credit bill | **Sales → Receivables** → collect to correct till |

## 5. End of day

1. **Finance → Daily reconciliation**  
   - Prefer **day-only** for “today’s till activity”.  
   - Use **full till** only if matching **Cash & bank** balances.
2. Count physical cash / check M-Pesa statements vs **Expected**.
3. Save reconciliation; report differences to the manager.
4. Log out.

## 6. Never do

- Share logins or leave POS unlocked.
- Sell without selecting batch when the system asks.
- Pay suppliers from the wrong account “to make numbers match”.
- Delete or re-receive the same GRN to “fix” stock without manager approval.
- Ignore go-live readiness / till ledger warnings.
